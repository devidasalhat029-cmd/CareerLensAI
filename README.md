🚀 CareerLens.ai

AI-Powered Career Guidance & Placement Preparation Platform

CareerLens.ai is an AI-powered career guidance platform designed to help students prepare for their careers and placements through personalized career analysis, skill development, resume building, mock interviews, job opportunities, and placement readiness tracking.

---

🎯 Project Objective

The main objective of CareerLens.ai is to provide students with a single platform where they can:

- Build and manage their career profile
- Create professional resumes
- Analyse their career readiness
- Identify skill gaps
- Practice AI-based mock interviews
- Explore job opportunities
- Track placement preparation progress
- Get personalized career guidance

⚙️ Installation & Setup

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project

cd CareerLensAI

3. Create virtual environment

python -m venv myenv

4. Activate virtual environment

Windows:

myenv\Scripts\activate

5. Install dependencies

pip install -r requirements.txt

6. Configure environment variables

Create a ".env" file:

GROQ_API_KEY=your_api_key_here

Do not upload ".env" or API keys to GitHub.

7. Run the application

python app.py

Open the application in your browser:

http://127.0.0.1:5000

🔐 Security

Sensitive information such as:

- API keys

- ".env" files

- Virtual environment files
